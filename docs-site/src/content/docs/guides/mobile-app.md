A Hearthwork mobile app is **in development**. It lives in a separate repository, and Android comes first. There are no downloads yet.

The idea is to use the model running on your own computer from your phone, through the same sharing and pairing described in [Use the model from another computer](/guides/other-computer/) and [Tailscale](/guides/tailscale/).

Today, nothing about the mobile app is required to use Hearthwork. Follow the [GitHub repository](https://github.com/BillyMRX1/hearthwork) for news.
